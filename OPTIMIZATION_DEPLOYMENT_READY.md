## 🎓 KEY LEARNINGS

### Optimization Patterns:

```javascript
// 1. Wrap components with React.memo
const MyComponent = React.memo(({ props }) => { ... });

// 2. Memoize static data
const options = useMemo(() => [...data], []);

// 3. Stabilize event handlers
const handleClick = useCallback(() => { ... }, [deps]);

// 4. Replace useState+useEffect with useMemo
const total = useMemo(() => calculate(), [deps]);

// 5. Add cleanup
useEffect(() => {
  const timer = setTimeout(...);
  return () => clearTimeout(timer);
}, []);
```

### When to Optimize:

✅ High-frequency components (rendered 10+ times)
✅ Components with expensive calculations
✅ Components passing callbacks to children
✅ Static data arrays/objects

### When NOT to Optimize:

❌ Simple components rendered once
❌ Props changing every render
❌ Premature optimization without profiling
