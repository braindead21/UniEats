## 🎭 Interactive Elements

### **Buttons**

```
Primary:   [Continue] [Next →] [Place Order]
Secondary: [Cancel] [← Back]
Icon:      [✏] [🗑] [×]
Link:      Change
```

### **Input Fields**

```
Text:      [Flat/House No.         ]
Number:    [Phone: 9876543210      ]
Textarea:  [Special instructions   ]
           [Max 200 characters     ]
Dropdown:  [Ring the bell        ▼]
Radio:     (●) Selected  (○) Not selected
Checkbox:  ☑ Checked  ☐ Unchecked
```

### **Cards**

```
┌────────────────────────────┐
│ Title                [Icon]│
│ Description                │
│ Additional info            │
│ [Action Button]            │
└────────────────────────────┘

States:
- Default (border: gray)
- Hover (border: orange, shadow)
- Selected (border: orange, bg: light orange)
```

## 🌟 Animation Effects

### **Step Transition**

```
Step 1 → Step 2
  Fade out left + Fade in right
  Duration: 300ms
  Easing: ease-in-out
```

### **Button Hover**

```
Default → Hover
  translateY(-1px)
  box-shadow: 0 4px 6px rgba(0,0,0,0.1)
  Duration: 200ms
```

### **Modal Open**

```
Overlay: Fade in (300ms)
Modal: Slide up + Fade in (300ms)
```

### **Success State**

```
✓ Icon: Scale up (0.8 → 1.2 → 1)
Green pulse effect
Duration: 600ms
```
